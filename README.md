# 🚗 AI 汽车设计工坊 · 小小汽车设计师

给孩子玩的网页小工具：选车型 / 颜色 / 风格 / 配件 → **亲手画一条车顶线** → AI 把这条线变成一张像模像样的汽车设计图 → 签名 → 下载。

灵感来自天津比亚迪迪空间新能源汽车科普馆四层的「AI 造车」互动区。

> ⚠️ **仓库里不含任何 API Key。** 项目不内置模型，谁用谁填自己的 Key（存在本机浏览器里，不上传、不进仓库）。

---

## 一、三分钟跑起来

### 1. 准备环境

需要 [Node.js](https://nodejs.org/) 18 以上（自带 `node`，无需 npm 安装任何依赖）。

```bash
node -v        # 确认能打印版本号
```

### 2. 启动

```bash
cd kid-car-designer
node server.js
```

浏览器打开 **http://localhost:8777**

> 一定要用这个地址。**不要直接双击 `index.html`**，也别用编辑器的静态预览地址 —— 那样 `/api/generate` 会打到别的服务器，报 `HTTP 404`。

### 3. 填自己的模型 Key

页面右上角点 **⚙ 设置模型**（第一次打开会自动弹出）：

| 服务商 | 填什么 | 默认模型 | 大致价格 |
|---|---|---|---|
| **火山方舟 · 豆包 Seedream**（推荐，中文理解好） | API Key（`ark-` 开头） | `doubao-seedream-5-0-260128` | ≈0.2 元/张 |
| OpenAI 兼容接口 | API Key | `gpt-image-1` | ≈$0.04/张 |
| 腾讯混元生图 | SecretId + SecretKey | 混元生图 3.0 | ≈0.2 元/张 |
| 本地试玩 | 不用填 | — | 免费 |

火山方舟 Key 获取与开通：
1. 打开 https://console.volcengine.com/ark → **模型广场**
2. 搜「豆包图像创作模型」→ 找到对应模型 → **开通**（开通后约 1–2 分钟生效）
3. 左侧 **API Key 管理** → 创建 Key，复制进页面的设置里

> 想换模型：设置里「模型 ID」填 `doubao-seedream-4-5-251128` 等即可，同样要先在控制台开通。

**不填 Key 也能玩**：选「本地试玩」模式，页面会用本地绘制的汽车兜底，选配置 → 画线 → 签名 → 下载的全流程都能走通，只是不出 AI 图。

## 二、怎么用

1. **选配置**：车型（9 种）/ 颜色（10 色）/ 风格（6 种）/ 脑洞等级 / 小配件（15 个，亮点为当前风格推荐）
2. **画轮廓**：在画布上从 ⭐车尾 一笔画到 ⭐车头，这条线就是车顶线
3. **点「✨ AI 设计我的车」**：等 40–60 秒出图；不满意点「🔁 换一版」
4. **签名**：在签名板上写名字（会变成彩色小字放在图的右上角）
5. **「🖼 生成最终图片」→「⬇️ 下载」**：每次生成覆盖上一版，只留最新一张

- 顶部 **🖼 汽车图片墙**：全部历史作品（最多 40 张）
- 「我的作品」页下方：最近 10 张，新作品渐显入场
- 作品和 Key 都存在**本机浏览器 localStorage**，换设备/清缓存会丢

## 三、它是怎么把「孩子画的一条线」交给 AI 的

不是把线翻译成一句话，而是**直接给图**：

1. 前端 `buildSketch()` 把那条线渲染成 1024×1024 的线稿 PNG（白底 + 黑色粗线闭合车身轮廓 + 两个轮子 + 地面线）
2. 作为 `image` 参考图随 Prompt 一起发给绘图模型，Prompt 里说明"这是小朋友亲手画的车顶轮廓，请沿用它的形状和走势"
3. 提示词同时叠加：车型 / 颜色 / 风格场景背景 / 脑洞等级 / 配件 / **斜前方 45° 展示角度**

所以孩子画的波浪车顶，出来的车就是波浪车顶——这是整个项目最有意思的部分。

关掉线稿直传：把 `config.json`（由 `config.example.json` 复制而来）里的 `ARK_USE_SKETCH` 改成 `"false"`。

| 文件 | 作用 |
|---|---|
| `index.html` | 整个前端（单文件，无框架、无构建），画布 / 配置 / 照片墙 / 设置都在里面 |

| `LICENSE` | MIT |

## 五、安全须知

- **Key 只存在使用者本机浏览器的 localStorage 里**，每次生成时随请求发给自己电脑上跑的 `server.js`，由它转发给模型厂商
- 后端**不写文件、不打日志**（带线稿失败时也只打印一句无敏感信息的提示）
- `config.json` 已被 `.gitignore` 忽略；提交前请确认没有把 Key 写进任何文件
- 如果 Key 不慎泄露：去服务商控制台**立即删除/轮换**该 Key

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 徽章显示「未连接本地服务」 | 没跑 `node server.js`，或不是用 `http://localhost:8777` 打开的 |
| 徽章显示「未配置模型 Key」 | 点 ⚙ 设置模型，填自己的 Key |
| 提示「模型还没开通」 | 去服务商控制台的模型广场开通；开通后有 1–2 分钟生效延迟 |
| 提示 401 / Key 无效 | Key 复制不全或已失效，重新生成 |
| 出图很慢 | 正常 40–60 秒；「狂想未来」档提示词更长，会更慢一点 |
| 出图不理想 | 换「脑洞等级」、换风格、多换几版；车顶线画得越有特点，出来的车越有意思 |
